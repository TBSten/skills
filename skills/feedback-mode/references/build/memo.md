# メモ（Memo）: ページと箇所ごとに書き溜める継続メモ

構築側の資料。凡例・用語、フィードバックとメモの違いと使い分けは `references/concepts.md`「フィードバックとメモ」。消化ループでの読み方は `references/loop/loop.md` §2.4。記録の例: `assets/templates/memo-file.example.md`。

出どころ: Web 参照実装（Astro 7 + Starlight の docs サイト）の Dev Toolbar の 2 つ目のアプリ【実績】。フィードバックモードと同じ dev 限定・同じ Sink・同じ「場所を一意に指す」手がかり（`locate.md`）の上に作る。Web 以外への移植は【未検証】。

## 1. 何を作るか

- 開いているページに、**ページのメモ**（1 つ）と**箇所のメモ**（選んだ要素・テキストごとに 1 つ）を書く。書くそばから自動で保存し、次に同じページを開くと戻る。何度でも直せる。
- ページ上には、箇所のメモの**印**（番号）を出す。印を押すとその欄へ、欄の「場所を表示」で本文のその場所へ飛んで光らせる。
- dev のときだけ。本番の dist に出ないことは、フィードバックモードと同じ検査で確かめる（toolbar アプリの id を検査パターンに足す）。

## 2. 保存の形【実績】

- 置き場: Inbox の中の `memo/<言語>/<ページのパス>.md`（トップは `index.md`）。Sink の `writeDoc` / `readDoc`（上書きする文書。`references/concepts.md`「Sink の契約」）で読み書きする。記録の採番・`list` には混ざらない。
- パスはページの URL から作るので、**検査が要る**: 言語は `^[a-z]{2,3}(-[A-Za-z0-9]{2,8})?$`、各段は文字・数字・`._-` だけ、`..` は拒否。Sink の側でも `safeDocPath` とシンボリックリンクの確認で置き場の外に出さない（二重に守る）。
- 書き込みは tmp に書いて rename（読み手に書きかけが見えない）。受け口では書き込みを 1 本ずつ直列にする（保存が追い越し合わない）。
- 中身: 見える部分は Agent 向け（frontmatter・`## ページのメモ`・`## 箇所のメモ` と各箇所の場所の手がかり）、末尾の HTML コメントに画面の読み直し用の JSON。**読み直しは JSON から**行う（見える部分を手で直しても画面には効かない、と割り切る）。JSON の `<` `>` は `<` `>` にして、コメントを閉じられないようにする。読み直せないファイル（壊れた・形が違う）は、**上書きしないよう保存を止めて**知らせる。
- 大きさの上限（本文・field の値・field の数・箇所の数・文書全体）を受け口で確かめる。

## 3. field は全ページ共有のひな形【実績】

- メモの欄には、自由に書く大きい本文のほかに、1 行の field（例: 「読みやすさ」「優先度」）を並べる。どの field を出すかは**全ページ共有のひな形**（`memo/_fields.json`）で、どのページで足しても・外しても全ページに効く。
- ひな形から外しても、そのメモの値は消さない（ファイルに残る。戻せば出る）。空の値は保存しない。ひな形は変わったときだけ書く。
- 名前は空白を詰め、空・長すぎ・重複・多すぎは落とす。壊れた `_fields.json` は既定に戻す。

## 4. 印の引き直し【実績】

箇所のメモは、選んだときの手がかり（`locate.md` の XPath・CSS セレクタ・テキストフラグメント・ソースの行・近くの見出し・本文の抜粋）を持つ。ページを開くたびに **XPath → セレクタ → テキストフラグメント → ソースの行** の順に引き直して印を付ける（テキストの選択はフラグメントを先に）。どれでも見つからなければ欄に「見つからない」と出し、メモは残す。

## 5. 時刻【実績】

- メモごと（ページのメモ・各箇所）に**最終更新時刻**を持ち、中身（本文か field の値）が変わったときだけ進める。箇所には作成時刻も持つ。
- **画面には出さない**（書いている人には要らない）。ファイルにだけ書く。loop が「記録とメモのどちらが新しいか」を判断するのに使う。

## 6. 自動保存【実績】

- 入力が止まって約 500ms で保存する。保存中に変わった分は、終わったあとにもう 1 回保存する。状態（読み込み中・未保存・保存中・保存済み・失敗）を端に小さく出す。
- 閉じる・`pagehide`・`visibilitychange`（hidden）で、未保存の分を送ってから片付ける。
- ページも箇所も空になったら、ファイルを書かない（または空の節だけ）。

## 7. 画面【実績】

- 幅 600px より広いときは右上の popover、600px 以下は下から出るシート（`interaction.md` §4 と同じ 16px・44px・`visualViewport`）。フィードバックと違い**幕は敷かない**（メモはページを読みながら書き溜めるので、ページは触れたままにする）。
- 箇所を選ぶ間は帯を出し、選んだら欄が増える。印を押して欄へ、欄から場所へ飛ぶときは、光らせる間だけパネルを引っ込める。
- Astro の Dev Toolbar は Esc の `keyup` でアプリを閉じる。こちらで扱った Esc の `keyup` は止める（閉じたあとに届く分も）。
