# 共通仕様: 満たすべき機能

どの adapter でも同じ「フィードバックモードが何をするか」。**必須**は全 adapter で満たす。**optional** は導入先で選び、setup の plan で「入れる / 入れない」を決める。実装の細部（Web の操作の作り方など）は adapter のファイルに書き、ここには振る舞いだけを置く。

## 1. 必須

| # | 機能 | 振る舞い |
|---|---|---|
| R1 | debug ビルドだけ | 本番の成果物に、コード・UI・送信先（URL・鍵）・依存・権限・受け口が入らない。主はビルド時に消すこと、実行時の `enabled` は保険。本番の成果物を `scripts/check-no-feedback-in-prod.sh`（Astro は `check-no-dev-tools-in-dist.sh`）で検査して CI で落とす |
| R2 | 入って出られる | 入口（メニュー・ホットキー・FAB・既存の debug menu の項目・toolbar）で入り、Esc（モバイルは閉じるボタン）1 回で出る。吹き出しを開いていても 1 回で出る |
| R3 | アプリの操作を止める | モード中は、クリック・タップ・キー・フォーカスの移動・ジェスチャ（戻る・シェイク）がアプリに届かない。プログラムからの click も止める。ダイアログ・モーダルの中も選べる |
| R4 | 部品を選ぶ | ポインタ・タップの下の部品を選び、輪郭と名前を見せる。選ぶ単位は「操作できる要素はそのもの、ほかは名前の付いた最も近い祖先、どちらも無ければその要素」。「親を選ぶ」で広げられる |
| R5 | 部品の名前 | 名前（Web は `data-fb`、Compose は `Modifier.fbTarget`、SwiftUI は `.fbTarget`）を外側からつないだ道筋（`ヘッダ/保存ボタン`）。名前の無い要素は「祖先の道筋 › 要素の説明」。行・項目は番号でなく内容で名付ける |
| R6 | コメントを書いて送る | 吹き出しに文を書いて送る。文が空でも送れる（「（書いていません）」）。成功したらモードを終える。失敗したら理由を吹き出しに出してモードを続ける |
| R7 | 文脈を自動で付ける | 選んだ位置・画面・要素の状態・ログ（差し込み口から）・スクリーンショットを付けて、`data.md` §3.3 の形の記録にする。節のオン/オフを選べる |
| R8 | 入力を壊さない | 入る前のフォーカスと入力中の欄を確定させずに外し、出たら戻す |
| R9 | 秘密を集めない | パスワード欄の値と個人的な入力の本文は集めない（字数だけ）。画面の状態はモデルから作り、表示の文字は拾わない。最後に redact を 1 回 |
| R10 | 置き場の規則を守る | 採番・上書きしない・ルートの外に出ない（`data.md` §3.1）。Sink の契約テストが通る |
| R11 | テストできる | ヘッドレス・偽データ・一時ディレクトリで「入る → 選ぶ → 書く → 送る → 記録ができる → 下の要素にクリックが届いていない → 出る」を確かめられる。本物の置き場・実データに書かない |

## 2. optional

| # | 機能 | 振る舞い | ひな形のコードがある adapter |
|---|---|---|---|
| O1 | スクリーンショット | モードの UI を**隠してから**、選んだ部品を赤枠で囲んで 2 枚（全体・周り 24px の切り抜き）撮る。撮れなくても送り、理由を書く。倍率は `min(dpr, 2)` | electron（`capturePage`）・dom（html2canvas を差し込む）・android / kmp（Compose の graphics layer）・ios（`drawHierarchy`）。astro は作り方だけ（modern-screenshot） |
| O2 | 下書き | 部品ごとに書きかけを残し、送ったら消す。空の下書きは残さない。「選び直す」は文を次の部品へ持っていく | dom（メモリ）。astro は作り方だけ（`sessionStorage`） |
| O3 | 複数選択 | Shift+クリックで足す・外す（上限 20）。`kind: elements`。記録の節とスクショの枠に番号 | 作り方だけ |
| O4 | テキストの選択 | 選んだ文字の範囲を指して送る（`kind: text`）。モードの外でも、選択 + 右クリックで入れる | 作り方だけ |
| O5 | ページ全体・アプリ全体 | 何も選ばずに送る（`kind: page` / `site`） | astro（page）・1 枚の HTML（page） |
| O6 | 場所を一意に指す手がかり | XPath・CSS セレクタ（引き直して確かめたものだけ）・テキストフラグメントの URL・ソースの行。`dirty` / `stale` | astro（XPath・セレクタ）。ほかは作り方だけ |
| O7 | popover | 幕を敷かず、選んだもののそばに浮かべる。外を押しても書いてあれば閉じない。header をドラッグで動かせる | astro（ドラッグは作り方だけ） |
| O8 | スマホ幅 | 600px 以下は下から出るシート。入力 16px 以上・押せる高さ 44px 以上・`visualViewport` に追従。タップは pointerup で判定 | astro |
| O9 | テーマ追従 | ページのダークテーマに合わせる | astro |
| O10 | メモ | ページと箇所ごとに書き溜める継続メモ（`data.md` §5） | 作り方だけ（`references/setup/web/optional/memo.md`） |
| O11 | オプションの記憶 | 節のオン/オフを覚える | dom（`localStorage`） |

「作り方だけ」のものは、Web の実アプリで動かした作り方が `references/setup/web/optional/interaction.md` にある（コードは無い）。

ひな形に無い組み合わせは、ほかの adapter の実装か作り方を移植して足す。

## 3. 同じ仕組みに乗る別の道具

| 向き | 道具 | 中身 | 読むもの |
|---|---|---|---|
| 人 → agent（agent が作った HTML） | 静的な HTML のフィードバック | 1 枚の HTML の項目にコメントし、まとめてコピーして会話に貼る | `references/setup/web/single-html.md` |
| agent → 人 | Review | agent の指摘を画面の印と popup で見せ、人はボタンで答える | `references/review/review.md` |
| 人の答え → 次の回 | 判断の記録 | 「直さない・このまま・後で・方針」を溜め、次の回に照らす | `references/review/decisions.md` |

Review の「直してもらう」は指摘を記録に変える（向きが人 → agent に戻る）。記録を archive すると元の指摘も消える（`review.mjs archived`）。
