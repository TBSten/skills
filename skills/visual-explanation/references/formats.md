# 見せ方と template.html の部品

どの変更にどの見せ方を使うかの表は rule `visual-explanation` (`.claude/rules/visual-explanation.md`) を正とする。ここには、選んだ見せ方を `assets/template.html` のどの部品で描くかだけを書く。

複数に当てはまるときは、読む人が最初に知りたいもの (たいてい「何が変わるか」) を 1 枚目にする。

| 見せ方 | template.html の部品 |
|---|---|
| Before / After | `.compare` + `.label.before/.after` |
| 仕組みの図 (タイムライン・競合の順番) | `.timeline` |
| 1 枚まとめ (コード + 実行結果) | `pre` を 2 つ (コード / 出力) |
| 消えるもの / 残るもの | `.compare` (ラベルを「消える / 残る」に) |
| 現状と目指す姿 (チケット) | `.compare` (ラベルを「いま / 目指す姿」に) |
| GIF (画面収録できる) | 使わない。画面収録をそのまま使う |
| GIF (画面収録できない) | 下の「実ログから GIF を作る」 |
| diff・`<details>` の出力・画像なし | 使わない。本文に直接書く |

## 1 枚の作り方

- 1 section 1 メッセージ。`<h2>` にそのメッセージを 1 文で書く。
- `.lead` に「何と何を比べたか / 何の順番か」を書く。
- `.note` に撮り方 (画面収録 / 実ログから描いた再現 / headless 描画) と、PR・コミット範囲・コマンドを書く。
- 実際の実行・実データから作る。モックは作らない。
- 色は `:root` のトークンだけを使う。プロジェクトにデザインシステムがあれば、トークンの値をそちらに合わせる。

## 実ログから GIF を作る

クラウドのセッションなど画面収録できない環境では、実際の実行ログを 1 コマずつ描いて GIF にする。

1. 実際に実行して、出力 (端末の出力・MCP の呼び出し記録など) を保存する。
2. 1 コマ 1 section で、ログを先頭から少しずつ増やした `pre` を書く。id は `frame-01`, `frame-02`, ... のように連番にする。
3. ライトだけ撮る: `node capture.mjs <html> <out-dir> --schemes=light`
4. GIF にする: `bash make-gif.sh <out.gif> <out-dir>/frame-*-light.png`
5. 本文には「実ログから描いた再現 (画面収録ではない)」と、元にしたログ・コマンドを書く。
